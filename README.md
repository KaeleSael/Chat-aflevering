Projekt beskrivelse
    En char-server hvor brugere af 3 niveauer kan kommunikere på kryds og tværs.
    Bruger af 3 niveauer har forskellige rettigheder
    All kommunikation er krypteret
    Mere info kommer... 


Start af forside:
    for at starte websiden, skal du skrive node app.js i din terminal
    åbn derefter hjemmesiden localhost:8010
